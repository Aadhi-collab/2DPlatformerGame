# Cape Jack - 2D Platformer Adventure

A 2D platformer game built in Godot where you play as Cape Jack, a daring adventurer on a quest to find the legendary **Ability-Kangaroo** and escape eternal doom!

## 🎮 Gameplay Overview

- **Objective:** Navigate challenging platforms, evade obstacles, and discover the hidden Ability-Kangaroo
- **Setting:** A mystical realm filled with deadly platforms and hidden secrets
- **Challenge Level:** Progressive difficulty as you advance through levels

## 🕹️ Controls

| Action | Key |
|--------|-----|
| **Move Left** | A |
| **Move Right** | D |
| **Jump** | Space |

## 📥 How to Run

### Requirements
- Godot 4.0 or later ([Download here](https://godotengine.org/download))

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aadhi-collab/2DPlatformerGame.git
   cd 2DPlatformerGame
   ```

2. **Open in Godot:**
   - Launch Godot Engine
   - Click "Open Project"
   - Navigate to the project folder and select `project.godot`

3. **Run the game:**
   - Press `F5` or click the Play button in the top-right
